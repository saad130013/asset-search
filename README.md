
# Asset Search App

تطبيق ويب بسيط باستخدام Streamlit للبحث في بيانات الأصول باستخدام رقم الأصل.

## طريقة التشغيل

1. تأكد من وجود Python 3.9 أو أحدث.
2. ثبّت المكتبات:
   ```
   pip install -r requirements.txt
   ```

3. شغل التطبيق:
   ```
   streamlit run search_app.py
   ```

4. أدخل رقم الأصل وستظهر تفاصيله من ملف Excel.
